# Code

This directory contains the source code used for data preprocessing, acoustic
feature extraction, model development, training, evaluation, statistical
analysis, external temporal validation, and figure generation.

## Repository structure

The code will be organised into the following components:

- `Preprocessing`: audio extraction, segmentation, and data preparation
- `Feature-Extraction`: log-mel spectrogram and acoustic feature generation
- `Models`: model architectures and model configuration
- `Training`: model training and hyperparameter configuration
- `Evaluation`: internal testing and statistical analysis
- `External-Validation`: analysis of the external temporal-validation recording
- `Figures`: generation of figures and tables reported in the manuscript

The required software packages and tested versions are documented in the
repository dependency files.
